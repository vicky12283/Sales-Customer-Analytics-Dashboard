# Sales & Customer Analytics Dashboard

## Overview
Business intelligence dashboard built in Power BI.

## Objectives
- Analyze sales trends
- Understand customer behavior
- Identify profitable products
- Regional performance analysis

## Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV

## Dashboard Pages
- Executive Summary
- Sales Trends
- Customer Segmentation
- Product Performance
- Regional Analysis

## Key Insights
- West region generated highest profit
- Technology category had best margins
- Repeat customers contributed 62% revenue
